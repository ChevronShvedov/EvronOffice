# EvronOffice

EvronOffice (Evron Office 7.4) — автономный офисный пакет от EvronTech в одном HTML-файле. Работает в браузере, без установки, с акцентом на локальную работу и приватность.

## Возможности

- **Writer** — документы
- **Slides** — презентации
- **Tables** — таблицы
- **Code** — редактор кода
- **Один файл** — достаточно открыть `Evron Office v7.4.html` в современном браузере
- **Офлайн-работа** — базовые функции доступны без интернета, если файл уже сохранён на устройстве
- **Локальное хранение** — содержимое и настройки по умолчанию хранятся на вашем устройстве
- **Форматы** — поддержка импорта/экспорта популярных форматов, включая DOCX, XLSX, PPTX, PDF, ODT/ODS/ODP, RTF, CSV, Markdown

## Скачать и открыть

1. Скачайте файл [`Evron Office v7.4.html`](./Evron%20Office%20v7.4.html).
2. Откройте его в современном браузере (Chrome, Edge, Firefox или другом актуальном браузере).
3. Выберите нужный модуль: Writer, Slides, Tables или Code.
4. Сохраняйте результаты через функции экспорта/сохранения в нужном формате.

## Важно

- Скачивание, открытие или использование EvronOffice означает принятие условий и документов из папки `docs/`.
- Делайте резервные копии важных файлов: черновики и настройки могут храниться в локальном хранилище браузера.
- Необязательный ИИ-ассистент подключается отдельно вашим ключом; при его использовании данные могут передаваться во внешние сервисы согласно их условиям.
- Открывайте и запускайте код/файлы только из доверенных источников.
