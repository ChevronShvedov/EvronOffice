6. КОНФИДЕНЦИАЛЬНОСТЬ И ДАННЫЕ

Evron Office работает локально в браузере. Содержимое документов не отправляется на серверы правообладателя; правообладатель не получает данных пользователя.

Черновики, настройки и недавние данные хранятся в локальном хранилище браузера на устройстве пользователя и могут быть удалены вместе с данными сайта. Файлы сохраняются только по действию пользователя.

Единственное исключение — необязательный ИИ-ассистент: условия его работы и передачи данных описаны в разделе 7. Без подключения ИИ-ассистента программа ничего не отправляет. Если без интернета недоступен шрифт оформления, браузер использует системный шрифт. Пользователь самостоятельно отвечает за сохранение резервных копий важных документов.

6.1. Собственные форматы. Файлы .evdoc, .evpres, .evsheet и .evcode — сжатые пакеты, предназначенные для открытия в Evron Office; старые файлы этих форматов продолжают открываться. PDF-файлы, созданные в Evron Office, открываются в любом браузере или программе для чтения PDF. В такой PDF вшивается полный редактируемый исходник документа (текст, слайды, таблицы, код вместе со скрытым и невидимым на странице содержимым). Пользователь самостоятельно решает, кому передавать такой PDF, и понимает, что получатель с Evron Office сможет восстановить из него исходный документ. Если PDF изменён сторонней программой, вшитый исходник может не совпадать с видимым содержимым страниц.

6.2. Запуск кода. Команда «Запуск» (F9) в редакторе Code выполняет JavaScript в изолированном потоке браузера (Web Worker) с ограничением по времени 5 секунд, а HTML, CSS и Markdown показывает в песочнице (sandbox iframe). Код выполняется только на устройстве пользователя и не отправляется правообладателю. Подгружать и запускать код из недоверенных источников пользователь вправе только на свой риск.

7. ИИ-АССИСТЕНТ (НЕОБЯЗАТЕЛЬНАЯ ФУНКЦИЯ)

7.1. Что это. ИИ-ассистент — чат справа от редакторов Writer, Slides, Tables и Code. Он помогает работать с текстом, презентациями, таблицами и кодом: предлагает варианты, которые пользователь сам применяет кнопкой. Ассистент ничего не меняет без действия пользователя.

7.2. Включение. Ассистент не работает, пока пользователь сам не введёт ключ сервиса OpenRouter (openrouter.ai) в разделе «Настройки → ИИ-ассистент». Правообладатель не предоставляет ключи, модели, баланс или доступ к сервису и не является стороной отношений пользователя с OpenRouter и разработчиками моделей.

7.3. Передача данных. При отправке сообщения на серверы openrouter.ai и выбранной пользователем модели передаются: текст сообщения; история переписки текущего редактора; если включено «Прикрепить…» — содержимое открытого документа, структура презентации, данные текущего листа (в пределах заданного лимита) либо код открытого файла или выделенный фрагмент; технические данные запроса, которые отправляет браузер. Эти данные обрабатываются по правилам и условиям OpenRouter и поставщика выбранной модели, которые пользователь принимает самостоятельно; часть бесплатных моделей может использовать запросы для обучения. Правообладатель Evron Office эти данные не получает, не хранит и не обрабатывает.

7.4. Что хранится. Ключ и настройки ассистента хранятся только в локальном хранилище браузера пользователя и не входят ни в файл программы, ни в сохранённые документы. Переписка нигде не сохраняется и удаляется при очистке чата, закрытии или перезагрузке страницы. Ключ можно удалить в любой момент кнопкой «Удалить ключ».

Пользователь самостоятельно: хранит ключ и не передаёт его третьим лицам; отвечает за расходы, которые списываются с его аккаунта OpenRouter при использовании платных моделей; решает, какие данные отправлять, и не отправляет пароли, ключи доступа, персональные данные третьих лиц, коммерческую тайну и иную информацию, передача которой запрещена законом или договором; соблюдает правила OpenRouter и поставщика модели; проверяет результат перед использованием.
