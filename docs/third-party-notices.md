# Уведомления о сторонних компонентах EvronOffice

**Документ:** Сведения о стороннем программном обеспечении  
**Продукт:** Evron Office 7.4 / EvronOffice  
**Версия документа:** 1.0  
**Дата публикации:** 2026-05-01

EvronOffice включает сторонние компоненты с открытым исходным кодом. Они принадлежат своим авторам и распространяются на условиях собственных лицензий. Настоящее лицензионное соглашение EvronOffice на эти компоненты не распространяется.

## Компоненты, встроенные в дистрибутив

| Компонент | Лицензия | Назначение |
|---|---|---|
| JSZip | MIT | Работа с ZIP-контейнерами docx, xlsx, pptx, odt, odp |
| SheetJS Community Edition 0.18.5 | Apache-2.0 | Чтение и запись xls, ods, xlsx |
| jsPDF 2.5.1 | MIT | Создание PDF |
| PptxGenJS | MIT | Создание pptx |
| PDF.js | Apache-2.0 | Чтение текста из PDF |
| CodeMirror 5 | MIT | Редактор кода |
| Liberation Serif, Liberation Sans, Liberation Mono | SIL Open Font License 1.1 | Шрифты для текста в PDF |

Тексты лицензий сторонних компонентов (на русском языке) можно посмотреть отдельно: в боте откройте этот документ и нажмите «📚 Лицензии компонентов», затем выберите нужный компонент — лицензию можно прочитать в чате или скачать файлом.

Оригинальные тексты лицензий также доступны у авторов и в репозиториях соответствующих проектов.

## Внешние сервисы (не входят в состав программы)

- **OpenRouter и модели поставщиков** — используются только при добровольном включении ИИ-ассистента пользователем (с собственным ключом). Не входят в программу, принадлежат своим правообладателям и регулируются условиями этих сервисов.
- **Telegram** — платформа доставки бота; использование регулируется условиями Telegram.

Актуальный перечень также отражён в Условиях использования (EULA).
